# Screenshots for the report

Figures for the written report (deliverable 3). The Act 4 set covers the four
things the spec asks to be demonstrated: **heap construction, extraction,
heapify, and the final sorted result.** Screenshots of the four AVL rotation
types are Partner A's, taken from the rotation demos in the dev launcher.

| File | What it shows |

| `01_main_menu.png` | Main menu, with the star total read from the save file |
| `02_campaign_map.png` | Four acts, twenty levels, stars earned and locked levels |
| `03_act1_1_traversal.png` | Act 1.1 — a random non-ordered binary tree, preorder patrol |
| `04_act1_2_reconstruction.png` | Act 1.2 — rebuilding a vault from preorder + inorder; unfilled rooms show `?` |
| `05_act1_3_heights.png` | Act 1.3 — heights entered bottom-up, a solved room marked gold |
| `06_act1_4_lca.png` | Act 1.4 — the two marked rooms whose routes have to meet |
| `07_act1_5_mirror.png` | Act 1.5 — the vault after `mirror()`, won with three stars |
| `08_act4_1_heap_construction.png` | **Heap construction** — a player swap, tree and array both updated, event log showing `Swap index 1 and 0` |
